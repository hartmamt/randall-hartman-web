A block theme for randallhartman.com.

== Description ==

The home of Randall Hartman's writing and his memoir, A God Awful God. Built only from
core WordPress blocks: every page, section and piece of writing is edited in the normal
WordPress editor. Reusable sections live under Patterns > Randall Hartman.
